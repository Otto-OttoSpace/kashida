kashida  ·  formerly arabitype

AI styles Arabic like it's Latin. العربية breaks.

Arabic is connected and cursive, and it carries diacritics. So letter-spacing shatters its ligatures, tight line-height crushes the tashkeel, uppercase is meaningless, and Latin-only fonts render it ugly. kashida catches all of it — and only where Arabic is actually present, so a pure-Latin file reports nothing.

$ npx kashida .

What it catches (in Arabic context)

  • letter-spacing / Tailwind tracking-* on Arabic → shatters ligatures
  • Tight line-height (leading-none/tight/snug, < 1.5) → crushes tashkeel
  • Small sizes (text-xs/text-sm, < 16px) → Arabic body too small
  • text-transform: uppercase → meaningless on Arabic, hides bugs
  • Latin-only font stacks → flagged via an Arabic-font allowlist (Inter, Cairo is clean)

Parser-verified, not regex

  • Gated on a real Arabic signal — Arabic glyphs, lang="ar"/dir="rtl", or an .arabic/[lang=ar] selector
  • Reads cn()/clsx()/cva()/template-literal class composition
  • Reads inline JSX style={{…}} objects and arbitrary Tailwind (text-[13px], leading-[1.2])
  • Report-only — it never edits your code. // kashida-ignore + kashida.config.json when you disagree
